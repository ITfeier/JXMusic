## 一、结论速览

| 问题 | 结论 |
|---|---|
| 扫码成功后提示「登录成功但登录态不完整（VIP 权益可能不可用）(error_code=20006)」 | **误报**。扫码 status=4 返回的 `token`+`userid` **就是完整登录态**；旧代码额外调用 legacy `loginservice.kugou.com/v1/login_by_token_get` 换登录态，该接口已废弃/协议不符（20006），失败后把「可选增强失败」误写成「登录态不完整」 |
| token+userid 是否够用（本机实测） | **够用**：用用户真实会话（脱敏）带 `Cookie: token=…; userid=…` 调 `m.kugou.com/app/i/getSongInfo.php?cmd=playInfo`，免费歌返回 `status=1` + 可播 `sharefs.kugou.com` 直链 |
| 修复 | 删除 legacy 换登录态调用与相关候选/降级逻辑；status=4 直接落 token/userid 建立会话；不再输出「登录态不完整」。取码协议（appid=1014/dfid='-'）实测未受限，**保持不动**（降低风险） |
| VIP 权益 | 用户为普通账号，验收只要求普通歌可播 + VIP 文案准确。Android 域接口（register_dev / v5/login_by_token / user_info / tracker）对 **web 型(1014) token** 实测均被拒（20006/20018/20017），故本次不做 VIP 增强；若将来需要 VIP 高音质，需迁移 Android 型 token（appid=1001 + 真实 dfid，见「未完成项」） |

## 二、假设验证（本机接口探针，真实用户会话；token 仅脱敏展示）

探针：`dart run tool/check_kg_login_state.dart`（只在本机命令行传 token，**不写盘、不入库、不提交**）。
原始输出：`证据-本机接口探针.txt`（token/userid 均为前 4 后 4 脱敏）。

| 步骤 | 接口 | 实测结果 | 说明 |
|---|---|---|---|
| A | `POST userservice.kugou.com/risk/v3/r_register_dev` | HTTP 200，`error_code=20006`（返回 JSON 而非密封二进制，解密失败、已排除误解密） | 设备注册被拒；且 web 型 token 不需要 dfid 也能取免费歌直链 |
| B | `POST login.user.kugou.com/v5/login_by_token` | HTTP 200，`status=0 error_code=20018` | Android 域刷新接口不接受 web 型(1014) token |
| C | `GET kugouvip.kugou.com/v1/get_union_vip` | HTTP 200，`status=0 error_code=20017` | 同上 |
| C2 | `POST relation.user.kugou.com/v1/get_my_userinfo` | HTTP 200，`status=0 error_code=20006` | 同上 |
| D1 | `GET m.kugou.com/app/i/getSongInfo.php?cmd=playInfo`（带 token+userid Cookie，免费歌 privilege=0） | **HTTP 200，status=1，url=`https://sharefs.kugou.com/…mp3`(len=148)** | **证明 token+userid 即完整登录态，普通歌可播** |
| D2 | `GET gateway.kugou.com/v5/url`（tracker，Android 签名） | `error_code=31833` | 需要 Android 型 token/设备，普通播放不走这条路 |
| D3 | `POST gateway.kugou.com/v6/priv_url` | `error_code=20010`（参数/权限） | 同上 |

> 结论：**20006 是「legacy/Android 域接口不接受当前 web 型登录态」的协议错误，不是用户登录失败。**
> 普通播放路径（getSongInfo + token/userid Cookie）在本机用真实 token 实测可用。

## 三、改动清单（仅写作用域内）

### 3.1 `lib/services/api/kugou_api.dart`

| 改动 | 说明 |
|---|---|
| 删除 `_completeLogin()` / `_loginByToken()`（legacy `login_by_token_get` 三候选 AES 约定） | 该接口已废弃（20006），是误报来源；一并删除"登录成功但登录态不完整"文案 |
| `pollQrLogin()` 重写 status=4 分支 | 直接 `_cookies['token']=[data.token]`、`_cookies['userid']=[data.userid]`，返回 `AccountSession`；昵称/头像取 data，`lastError=null`（登录成功，无警告） |
| status=0/1/2/错误码 | 保留原语义：过期给"二维码已过期"；2=已扫码待确认（静默等待）；非 0 error_code 给具体原因 |
| 取码/轮询协议 | **保持原 Web 协议不变**：`/v2/qrcode`、`/v2/get_userinfo_qrcode`、appid=1014、plat=4、clientver=8131、dfid='-'、`_sign` 大写 MD5；本机实测未受限，按监国要求不做 1001/register_dev 迁移 |
| `getPlayUrl()` | 主路径保持 `getSongInfo`（带登录 Cookie）；wwwapi 兜底；本次补充注释说明"登录后免费歌实测可播" |
| 删除未使用的 `_ensureDeviceIdentity/_registerDevice/_refreshLoginByToken/_fetchPrivUrl/_androidOptions` 等 Android 域实验代码 | 保持最小改动，避免未验证路径进入播放链路 |

### 3.2 `lib/services/api/kg_crypto.dart`（新增工具，供探针/单测与未来 Android 迁移）

- `webSalt` / `androidSalt` / `registerSalt`、`randomString` / `randomGuid` / `calculateMid`
- `signWeb`（Web MD5 双夹盐）、`signAndroid`（Android 签名，值排序 + body 原文）、`signRegister`（值排序 + 1014 双夹）
- `playlistAesEncrypt/Decrypt`（随机 6 位 key → md5[0:16] AESKey、md5[16:32] IV，AES-128-CBC/PKCS7，base64）
- `rsaPkcs1EncryptHex`（PKCS#1 v1.5，对应 `rsaEncrypt2`）
- 说明：当前 App 主链路未使用这些函数（Web 协议够用）；保留用于本机验证记录与后续「Android 型 token / VIP 权益」迁移，且被单测/探针覆盖。

## 六、未完成项与风险（如实）

1. **VIP 高音质/权益未实现**：当前 web 型(1014) token 对 Android 域接口（register_dev/v5/user_info/tracker）均被拒（20006/20018/20017，本机实测）。如后续要支持 VIP 歌曲，需要：
   - 取码改用 appid=1001 + `srcappid=2919` + `plat=4` + `type=1`（参考 MakcRe login_qr_key.js）；
   - 先 `register_dev` 拿真实 dfid（当前对 web token/假 dfid 返回 20006，需在 Android 型上下文重试）；
   - 取链改 `v6/priv_url`（Android 签名 + tracker_param.key）或 `v5/url`（signKey）。
   这些代码已在探针/`kg_crypto` 中实现并验证签名/加密向量，但**未接入 App 主链路**，属后续任务。
2. **`lastError` 语义**：酷狗播放失败目前仍由播放层给通用提示；本次未在接口层区分"VIP 受限/普通失败"（settings_page 不在本任务写作用域）。若需要更精细文案，需另开任务改 UI/播放层。
3. **接口易变**：酷狗 Web 登录协议（appid=1014/dfid='-'）为逆向协议，随时可能改版；失效特征与替换方式见 `docs/接口清单.md`。
4. **设备指纹**：本次保持 dfid='-'（官方 JS 无 cookie 时的默认值），未做设备注册；普通播放实测不受影响，但极端风控场景可能触发验证。
