# 立项单 · QQ/酷狗扫码登录二维码生成修复

- 项目：JXMusic（`D:\Project\yinyue\JXMusic`）
- 提出：用户
- 日期：2026-11-08
- 类型：缺陷修复（P0）

## 一、目标

设置页点击「QQ音乐 登录」「酷狗音乐 登录」时，能稳定拿到可扫描的登录二维码并完成轮询；
无法登录时给出准确的失败原因，而不是笼统的「二维码获取失败」。

## 二、现状（监国已取证）

| 平台 | 当前实现 | 实测结果 |
|---|---|---|
| QQ | `ssl.ptlogin2.qq.com/ptqrshow` + `appid=716027609&daid=383&pt_3rd_aid=100497308&u1=...` | **HTTP 403**；去掉 `u1/daid/pt_3rd_aid` 后返回 200，但仅 441 字节，是占位图不是真二维码 |
| 酷狗 | `gateway.kugou.com/v2/login/qr/key` + MD5 签名 | **HTTP 502**；`login-user.kugou.com/v1|v2/qr` 404；`mobiles.kugou.com` 返回 `Access Deny !!!` |

## 三、成功标准（验收口径）

1. **QQ**：调用修复后的取码方法，返回 `{qrUrl, key}`，其中 `qrUrl` 为 `data:image/png;base64,...`，
   PNG 尺寸为 **111×111**（真二维码特征；注意该尺寸 PNG 压缩后仅约 430~450 字节，**不能按字节数判断真伪**），
   `key(qrsig)` 长度 > 40；**连续两次取码图片不同**（排除静态占位图）；用该 key 轮询 `pollQrLogin`
   能拿到 `ptuiCB('66'/'67')` 等待态并返回 `null`，而不是抛异常/403。
2. **酷狗**：调用修复后的取码方法，返回 `{qrUrl, key}`，`qrUrl` 非空且可渲染（PNG/base64 或官方二维码图 URL），`key` 非空；轮询返回 `null` 表示等待，不抛异常。
3. `flutter analyze lib` 零问题；`flutter test` 全绿（不新增失败）。
4. 失败时设置页提示具体原因（网络/风控/接口变更），不显示错误的「二维码获取失败」。
5. 修复不得影响其他平台（网易云扫码、搜索、播放、下载、音乐库）。

## 四、不做什么

- 不做 QQ/酷狗 的账号密码登录、Cookie 手动粘贴登录（本轮只修二维码生成与轮询）。
- 不改动网易云扫码实现。
- 不引入新的第三方登录代理服务（不上传用户 Cookie 到第三方）。
- 不改动播放/下载/音乐库等无关模块。

## 五、平台与约束

- Flutter 3.44，`D:\Programs\flutter\bin\flutter.bat`。
- 只允许修改各自任务的写作用域文件；不执行 `git commit`（由监国统一提交）。
- 修复必须"接口级实测"证明：用 PowerShell/Dart 脚本调用真实接口拿到证据，不能只靠读代码推断。

## 六、风险

- 平台风控与接口随时变化，可能只能做到「当前网络下可用 + 失败原因准确」。
- QQ 403 可能是 IP 级风控，若确认无法绕过，需降级为明确提示 + 备选登录方式说明（本轮不实现备选）。
- 无真机/无 GUI 交互验证条件，扫码成功链路只能验证到「取码 + 轮询等待」这两步。

## 七、阶段二（2026-11-08 追加）

用户指示：**"如果找不到（官方接口），就用网上现成的可用的接口接入也行；后期接口失效了再想办法换新接口。"**

因此阶段二目标：

1. **酷狗登录态补全**：扫码确认后接入公开可用的官方 Web 协议 `loginservice.kugou.com/v1/login_by_token_get`
   （AES-CBC/PKCS7 + textbook RSA，参数与密钥来自官网 JS 与公开仓库实现），换取完整登录 cookie（vip_type/vip_token 等）。
   失败时降级为 userid+token 并提示"登录态不完整"，不阻断登录。
2. **QQ 换登录态加固**：check_sig / authorize / QQLogin 三步增加候选域名、超时与逐级 `lastError`，
   QQLogin 支持备用 base 重试（授权 code 一次性，不得重复消费）。
3. **接口可替换性**：新增 `docs/接口清单.md`，记录每个接口的当前实现位置、候选与替换步骤，后续失效按文档一处修改。
4. 验收口径：门禁全绿；`tool/check_kg_token_get.dart` 证明 token_get 端点可达且失败降级正确；
   如实声明"扫码成功后的兑换链路仍未经真机端到端验证"。
