# PRD：本地音乐自定义路径与加密格式支持（v0.10.0+19）

> 需求编号对应验收；每个 REQ 必须能被脚本/命令/截图验证。监国代拟，唐未单独召集（范围明确）。

## 1. 用户故事

- 作为用户，我把 QQ 音乐/网易云/酷狗下载的加密歌曲放在任意目录，希望 App 能直接扫描并播放，而不是只能扫应用自己的下载目录。
- 作为用户，我希望记住我配置的音乐目录，下次打开自动扫描；目录可以随时增删。
- 作为用户，手机上有大量 mp3/flac，希望常用格式都能识别播放。

## 2. 功能需求与验收口径

### REQ-1 目录管理（自定义路径）

- 本地音乐页「扫描目录」打开「音乐目录管理」底部弹层：
  - 列出已配置目录（完整路径），可删除；
  - 「添加目录」：目录浏览器选择，或手动输入路径；
  - 「开始扫描」：扫描全部已配置目录，合并结果按绝对路径去重；
  - 显示「解密缓存占用 + 清理」入口。
- 配置存 Hive `jx_settings` 的 `local_scan_paths`（`List<String>`），重启保留。
- 首次使用（无配置）自动预填默认候选目录（应用外部目录、Download、Music、常见平台下载目录中存在的项），用户可删改。
- 非法/不可访问目录：扫描时跳过并在 UI 显示该目录的错误原因，不影响其它目录。
- 验收：`test/local_paths_test.dart`（增删/持久化/去重/默认值）+ widget 测试（弹层增删渲染）+ 模拟器 E2E 截图。

### REQ-2 Android 存储权限

- 未授予「所有文件访问权限」时，本地音乐页顶部显示横幅：「需要「所有文件访问」权限才能扫描自定义目录」+「去授权」按钮。
- 点击后调起系统授权页（permission_handler：Android 11+ 用 `manageExternalStorage`；Android 10 及以下无「所有文件访问」概念，退路为 `Permission.storage`——请求顺序为 manage 优先、storage 兜底）。返回后刷新状态。
- Manifest 声明 `MANAGE_EXTERNAL_STORAGE`。
- 验收：模拟器上未授权/已授权两态截图；授权后能扫描 `/sdcard/Download/...`。

### REQ-3 加密格式识别与播放

- 扫描识别扩展名集合（见 `LocalAudioFormats.encryptedExtensions`）。
- 点击加密歌曲：先解密到缓存（显示「正在解密…」进度），成功后播放；失败弹窗显示具体中文原因（如「酷狗 KGG 格式需要客户端密钥，暂不支持离线解密」）。
- 队列播放（播放全部/自动下一首）时，加密歌曲由播放器 urlResolver 懒解密。
- 支持格式：
  - 网易云 `.ncm`（含内嵌元数据/封面）；
  - QQ `.qmc0/.qmc2/.qmc3/.qmcflac/.qmcogg/.mflac/.mflac0/.mgg/.mgg1/.bkcmp3/.bkcflac/.tkm`（v1 静态密钥 + v2 尾部密钥 TEA 派生；musicex 尾部若失败给提示）；
  - 酷狗 `.kgm/.kgma/.vpr`（公钥表 8MB，覆盖 128MB 音频）；`.kgg` 明确「暂不支持」。
- 魔数校验（R-21 裁决）：识别入口为**扩展名**（与用户实际文件命名一致）；解码前用 `canDecode` 校验魔数/尾部结构，扩展名与内容不符时明确报错；不做「无扩展名/错误扩展名的主动魔数识别」（那类文件视为用户改名/损坏场景，由解密失败提示兜底）。NCM 魔数 `CTENFDAM`，KGM/VPR 前后 16 字节 magic，QMC 以扩展名 + 尾部结构判断。
- 验收：`test/local_formats/ncm_qmc_test.dart`、`kgm_test.dart`（合成样本回环 + 已知常量向量）；E2E 至少一首 NCM 合成样本播放成功；失败路径单测覆盖。

### REQ-4 常用格式

- 直接扫描播放集合：mp3/flac/m4a/aac/ogg/opus/wav/wma/ape/aiff/aif/dsf/dff/mka。
- 元数据：能读则读（audio_metadata_reader），读不到回退「歌手 - 歌名」文件名解析；封面能提取则缓存。
- 验收：单测扫描夹具目录（普通文件不触发解密器）+ 模拟器播放一首 mp3/flac。

### REQ-5 解密缓存

- 缓存目录：应用支持目录下 `decrypted_audio/`；文件名 `sha1(源路径|大小|mtime)` + 输出扩展名。
- 同一文件并发请求合并（避免重复解密）。
- 二次播放直接命中；缓存超过 1.5GB 或 400 个文件时按最近访问时间淘汰。
- 验收：单测（命中/并发合并/清理）+ 手动检查目录。

### REQ-6 元数据与列表展示

- NCM 扫描时直接展示标题/歌手/专辑/封面；QMC/KGM 显示文件名回退信息，首次播放解密成功后回填标题/歌手/专辑/封面并刷新列表。
- 加密条目显示平台加密标签（网易云加密 / QQ加密 / 酷狗加密）与「需解密」标识。
- 验收：widget 测试 + E2E 截图。

### REQ-7 播放全部

- 列表顶部「播放全部」：以当前列表为队列，当前项先解密再播；后续加密项由 resolver 懒解密。
- 验收：E2E 队列自动下一首（合成样本 2 首）。

## 3. 非功能需求

- 扫描大型目录不卡 UI：分阶段 `await`，进度回调，最多 2000 个目录、跳过隐藏目录。
- 解密失败不崩溃、不产生半截缓存文件（写临时文件后 rename）。
- 不破坏既有功能：`flutter test` 全量绿。
- 隐私：解密缓存仅本机应用目录，不上传。
