## 6. 《森林之心》C8——**部分采信（P2，需修订一句）**

**报告现状（§5.5，快照 19:08）**：探针 L0145–L0147 显示新解析直链 + CDN 206 音频 → 写「排除『直链失效/CDN 拒绝/未登录』三个假设；问题范围收敛到 `_playAt` 之后」→ 归入 B 类播放层。

**QA 意见**：
1. 「未登录」可排除 ✓（vip=false 且 url 可得）；「CDN 拒绝」可排除 ✓（Range 206）；**「直链失效」不能排除**——该曲复现入口是「音乐库 → 历史」（上一轮 QA `docs/projects/播放链路修复/测试报告.md:266-271`；`docs/项目状态.md:92`），历史回放走 `resolveAndPlay` 时**跳过 `getPlayUrl`**（`playback.dart:81–88`），打开的是历史里持久化的旧 `audioUrl`（`song.dart:78/91`、`library_store.dart:94–97`），而探针验证的是**新解析**的直链，二者不是同一条 URL。因此「排除直链失效」不成立。
2. 「播放层」方向已有旁证：《7 Years》现场（同一库、同类现象：兜底候选解析+CDN 正常，但 `AudioTrack ... 0 frames delivered`、自动跳下一首、迷你条 0 进度）说明 libmpv→AudioTrack 层确实存在静默失败。故 B 类方向**部分采信**；但《森林之心》究竟是历史旧 URL 失效还是播放层，仍未被区分。
3. 修订建议（一句话成本）：§5.5 改为「排除未登录/CDN 拒绝；**未排除历史持久化旧直链**；播放层失败有《7 Years》现场旁证，属 B 类未细分」。可选实验：E1 删除该历史条目后从搜索页重播；E2 对比历史入口与搜索入口的 logcat；E3（代码）在线曲回放前重解析或历史只存 id。
