网易云封面 403 根因隔离实验（宿主 dart:io，2026-11-09 01:33 ~ 01:40）
测试 URL: https://p1.music.126.net/XtBk-KKRHFBHI87HZE9ljQ==/109951173904350931.jpg（及其 ?param=500y500 变体）

方式                                          | 状态码
无自定义头（dart:io 默认 UA）                  | 403
headers.set('user-agent', Chrome UA)          | 200
headers.add('user-agent', Chrome UA)          | 403  <-- Flutter Image.network(headers:) 内部用的是 add
headers.set('user-agent', 'Dart/3.13 (dart:io), Chrome UA') | 403
add Chrome UA + set Referer                   | 403
组合 UA + set Referer                          | 403

curl 对照（同一 URL）：
adb shell curl -A 'Mozilla/5.0 (Linux; Android 13)' -H 'Referer: https://music.163.com/' '...jpg?param=500y500' -> 200
宿主 curl -A '<Chrome UA>' -H 'Referer: https://music.163.com/' '...jpg?param=500y500' -> 200
宿主 curl -A 'Dart/3.13 (dart:io)' '...jpg' -> 403

结论：403 由「请求头里 UA 是 Dart 默认值或与浏览器 UA 组合成两段」导致，不是 param/Referer/防盗链问题。
修复（task-4）：JXNetworkImage 用共享 HttpClient.userAgent 设置单值 UA，请求头只 set Referer。
复测：最终包冷启动后 logcat 中『封面』失败日志 0 条，首页/搜索/播放页网易云封面均出图。
