## 5. task-4：网易云封面 403 修复与复测（单列）

### 5.1 问题现象（修复前，必报原文）

首版 task-2 把封面方案改为「补 `?param=500y500` + 失败重试原图 + 按域名 Referer」，但真机/模拟器冷启动后 logcat 仍全部 403。原始日志（excerpt）：

```
11-08 17:36:11.326  2353  2353 I flutter : [JXMusic] 封面加载失败 url=https://p2.music.126.net/OeS9k1YTY7U56AxgPPBJSQ==/109951173944588617.jpg?param=500y500 error=HTTP request failed, statusCode: 403, https://p2.music.126.net/OeS9k1YTY7U56AxgPPBJSQ==/109951173944588617.jpg?param=500y500
11-08 17:36:11.868  2353  2353 I flutter : [JXMusic] 封面重试仍失败 url=https://p2.music.126.net/XtBk-KKRHFBHI87HZE9ljQ==/109951173904350931.jpg error=HTTP request failed, statusCode: 403, ...
```

→ 结论：**两个 URL 候选（带 param / 原图）都 403，说明不是 URL 形式/Referer 问题**，判定 task-2 封面项 **FAIL**（当时已回报监国与 song-player）。

### 5.2 根因（dart:io 实测隔离）

宿主 dart:io 对同一网易云图片地址的对照实验（`logs/cover-403-rootcause.txt` 摘要，原始脚本复跑见 song-player 的 `tool/check_cover_image.dart`）：

| 请求方式 | 状态码 |
|:--|:--:|
| 无头（dart:io 默认 UA） | 403 |
| `headers.add('user-agent', Chrome UA)`（Flutter `Image.network(headers:)` 内部行为） | 403 |
| `headers.set('user-agent', Chrome UA)` | 200 |
| 手工组合 UA `Dart/3.13 (dart:io), Mozilla/…Chrome/126…` | 403 |

根因：Flutter 3.47.8 的 `NetworkImage` 用 `request.headers.add(name, value)`，与 dart:io 默认 UA 组成**两段 UA**；网易云 CDN 对这种组合 UA 返回 403。`param`/`Referer`/重试都不能解决。

### 5.3 修复（task-4）

`song-player` 在 `lib/ui/cover.dart` 新增自定义 `JXNetworkImage extends ImageProvider`：

- UA 通过**共享 `HttpClient.userAgent`** 设置（单值，等价 `set`），不再走请求头 add；
- 自定义请求头只 `set` Referer（按域名：网易云 `music.163.com` / QQ `y.qq.com` / 酷狗 `m.kugou.com`）；
- 非 200 抛 `NetworkImageLoadException`（带 statusCode，诊断日志可见）；失败时从 ImageCache 清掉自身，保证重试真正重发；
- `Image` 用 `frameBuilder` 显示占位，失败仍走 `errorBuilder` 诊断 + 一次 URL 变体重试；
- 新增 `tool/check_cover_image.dart`（联网探针）与 `test/cover_image_test.dart` 更新。

### 5.4 复测（PASS）

task-4 最终包（01:47:33 构建，sha256 `D3FC308B…`）卸载重装后冷启动：


## 6. task-5：音源按钮被撑成整行通栏的回归修复与复测（单列）

> 该回归由监国在 QA 首轮截图 `14_player_page.png` 中发现，QA 首轮用例只断言「只有音源二字/不压 Chip」，**漏了尺寸断言**，属 QA 用例设计缺口，已在 §4.1 补 C3b 用例。

### 6.1 问题现象（修复前）

- 证据：`screenshots/2026-11-09/14_player_page.png`（**回归证据（修复前）**）。
- 现象：播放页进度条上方的「音源」按钮不是右侧小胶囊，而是**横跨整行的灰色通栏条**。
- 量化（脚本 `logs/measure_source_button.py` 测量 1080x1920@480dpi 截图）：按钮包围盒 x=[72,1007]，宽度 **936px = 312.0dp**（约整行）。

### 6.2 根因

`lib/ui/player/player_page.dart` 的 `_SourceSwitchButton` 在 task-2 精简时给 `Container` 加了 `alignment: Alignment.center`。Flutter 的 `Container` **一旦设置 `alignment` 且父级约束是 bounded**（此处父级 `Align(centerRight)` 传入 bounded maxWidth），就会撑满可用宽度；旧实现紧凑是因为没有 `alignment`（靠 `Row(mainAxisSize.min)` 定尺寸）。

### 6.3 修复（task-5）

仅改 `_SourceSwitchButton`：

- 去掉 `Container.alignment`（并加注释禁止再加回）；
- child 改为 `Row(mainAxisSize: MainAxisSize.min, mainAxisAlignment: MainAxisAlignment.center, children: [Text('音源')])`；
- `constraints: BoxConstraints(minWidth: 64)` 保证最小点按尺寸，高度 26dp 不变；
- 加 `key: Key('sourceSwitchButton')` 供测试定位；
- 文案仍只有「音源」，点击仍弹「选择音源」面板，右对齐不变。
- 测试：`test/player_page_layout_test.dart` 增加按钮宽度 64~120dp（且小于半屏）、高 26、无「音源 ·」文案、`Chip bottom ≤ 按钮 top`、点击弹面板等断言（360x640 含/不含安全区两种场景）。

### 7.3 工作树包含并行会话改动（流程风险，已按监国口径处理）

工作树混有并行会话「扫码登录修复」的改动（`settings_page.dart`、`qq_api.dart`/`netease_api.dart` 的部分片段、相关 test/tool/docs）。这些改动与本轮 4 缺陷同树未提交，**若直接提交会混在一个 commit**；建议提交时按文件/区段拆分或由监国统一收口。本报告对它们的正确性不作结论。

### 7.4 评审发现的小问题（建议，不阻断发布）

1. **失败态语义合并**：`PlaylistListPage._error` 只在 `_fetchPage` 抛异常时触发；而各平台 API 内部 `catch → return const []`，网络失败时页面显示「暂无歌单（平台接口可能临时不可用）」+ 重试，而不是「加载失败」。功能可用，建议后续让 API 回传失败状态或在页面层区分空/失败。
2. **非网易云域名失败会重复请求同一 URL 一次**：`JXCoverImage` 重试逻辑对所有域名生效，非网易云 URL 两个候选相同，`ValueKey` 变化后会再请求一次同 URL。仅浪费一次请求，不影响正确性。
3. **调试日志过滤串**：任务描述用 `Select-String "JXMusic 封面"`，实际输出为 `[JXMusic] 封面加载失败 …`（中间有 `] `），直接按该串过滤会漏；建议用 `封面` 或 `JXMusic] 封面`。
4. **构建包体积巧合**：task-4 前后 APK 字节数恰好相同（106,674,209），已通过解包 `libapp.so` 字符串验证新代码（`JXNetworkImage`）确实在包内，并以运行日志 0 条 403 交叉确认，排除旧包误测。
