| 1 | **首页永久加载态（阻断）** `home_page.dart:24/44/93` | `_loading` 初值 `true`，`initState → _load()` 被自身守卫 `else if (_loading) return;` 弹回，全文件唯一置 `false` 在 `:93`（不可达） | 0.9.3（`06c96d3`）引入的回归；冷启动首页永远转圈，推荐歌单/榜单/热榜整块不可用，刷新与切回自动刷新全被挡。**这是本轮唯一阻断项，1 行可修** |

## 四、安全清单（无阻断，按处理顺序）
