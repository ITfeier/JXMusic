## 二、已完成能力

1. 聚合搜索 / 榜单 / 歌单（QQ音乐、网易云、酷狗）+ 本地音乐
2. 播放器：队列、循环模式、拖动、音量/静音、倍速、歌词滚动、自动解析直链（自动下一首可连续播）
3. 账号：三平台扫码登录，登录态 Hive 持久化，可退出登录
   - QQ 扫码：取码（ptqrshow，不带 u1）+ 轮询（u1=graph login_jump）已修复实测通过；换登录态改为 check_sig → authorize → musicu QQLogin（**待真机实扫端到端验证**）
   - 酷狗扫码：旧 gateway 协议下线，改用官方 Web `login-user.kugou.com/v2/qrcode` 取码 + `get_userinfo_qrcode` 轮询，实测通过
   - 酷狗登录态补全：扫码确认后接 `loginservice.kugou.com/v1/login_by_token_get`（AES-CBC/PKCS7 + textbook RSA，三套密钥/参数候选按序尝试），失败降级为 userid+token 并提示"登录态不完整"
   - QQ 兑换链路：check_sig / authorize / QQLogin 候选化 + POST→GET 降级 + 逐级 lastError + 20s 超时（授权 code 只在最后一步重试，不重复请求 authorize）
   - 酷狗补全的登录 cookie 已用于播放链接解析（`getPlayUrl` 携带 Cookie，仅发 kugou.com）
   - 失败提示：`MusicPlatformApi.lastError` 由接口层回报，设置页取码/轮询/登录成功降级都会展示
   - 接口清单与失效替换指引：`docs/接口清单.md`
4. 音乐库：收藏、播放历史（去重、200 条上限）、自建歌单、下载管理
5. 下载：播放页下载当前歌曲；音乐库「下载」页可播放/定位/删除
6. 桌面：全局快捷键、窗口置顶、系统托盘（关闭收进托盘）、迷你播放窗口
7. Android 发布：release 签名、INTERNET/媒体权限、明文流量放行

## 五、下一步（按优先级）

1. **真机扫码验收**（唯一阻塞项）：用手机 QQ/酷狗 App 实扫一次，确认「扫码 → 确认 → 兑换登录态 → VIP 播放」完整链路；失败时把设置页的 lastError 文案贴回来即可定位
2. **移动端可用性**：MediaStore 扫描系统音乐库 + 通知栏/锁屏媒体控制（需新增原生代码或插件，且当前无真机可验证）

## 六、卡点与风险

- **未真机扫码**：酷狗 `login_by_token_get` 的 status==1 / secu_params 解密、QQ 真实 p_skey→code→musicid/musickey 均未端到端执行；加密实现正确≠服务端密钥派生约定正确（酷狗三候选即兜底）
- 酷狗三候选按序尝试存在"token 被首次请求消费但响应丢失"的幂等风险；失败会降级为 userid+token 会话，不阻断登录
- 平台接口会变动：QQ 带 u1 的请求在本机出口仍被 403；接口失效按 `docs/接口清单.md` 一处替换（公共参数/候选列表已集中）
- 本轮所有验证均为「静态分析 + 单测 + 接口级实测」，GUI 交互未在真机/桌面实际点击验证
- APK 体积约 101MB（libmpv + 托盘等原生依赖），如需缩小需裁剪 ABI 或按需打包
