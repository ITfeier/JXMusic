## 二、已完成能力

1. 聚合搜索 / 榜单 / 歌单（QQ音乐、网易云、酷狗）+ 本地音乐
   - 首页分平台推荐歌单（0.9.8 起 QQ 歌单标题乱码已修：接口强制 UTF-8），每行「更多」进入「<平台> · 全部歌单」分页网格页（滚动触底加载、空态/失败重试、点卡片进详情）
2. 播放器：队列、循环模式、拖动、音量/静音、倍速、歌词滚动、自动解析直链（自动下一首可连续播）；播放页「音源」二级按钮可切换同曲其它平台音源（保留进度、失败给出具体原因、不静默换歌）
   - 0.9.8：音源按钮精简为「音源」二字 + 紧凑胶囊；播放页矮屏（360x640dp）按可用高度自适应封面，平台 Chip 不再被压住
   - 0.9.8：封面链路重做——网易云搜索批量补封面（`/api/song/detail`）；修复网易云图片 403（Flutter `Image.network(headers:)` 的 `headers.add` 造成重复 UA → 自定义 `JXNetworkImage` 用 `HttpClient.userAgent` 单值 UA）
3. 账号：三平台扫码登录，登录态 Hive 持久化，可退出登录
   - QQ 扫码：**已模拟器实扫端到端通过**——ptqrshow 取码（不带 u1）→ ptqrlogin 轮询（u1=graph login_jump）→ check_sig 换 p_skey（**忽略服务端同名空值 Set-Cookie，避免有效 p_skey 被清空**）→ authorize 取 code（双重编码 redirect_uri 优先 + 明文兜底）→ musicu QQLogin 换 musicid/musickey；重启后登录态保持
   - 网易云扫码：**已模拟器实扫端到端通过**——官方 **eapi** 协议（`/eapi/login/qrcode/*`，AES-128-ECB + 客户端指纹 Cookie + `type:"3"`）；旧 `/api` + `type=1` 会被服务端 8821 拒绝；803 从响应体/Set-Cookie 双通道取 `MUSIC_U`，登录后播放请求带 Cookie（仅 163.com）
   - 酷狗扫码：旧 gateway 协议下线，改用官方 Web `login-user.kugou.com/v2/qrcode` 取码 + `get_userinfo_qrcode` 轮询，实测通过
   - 酷狗登录态补全：扫码确认后接 `loginservice.kugou.com/v1/login_by_token_get`（AES-CBC/PKCS7 + textbook RSA，三套密钥/参数候选按序尝试），失败降级为 userid+token 并提示"登录态不完整"
   - QQ 兑换链路：check_sig / authorize / QQLogin 候选化 + POST→GET 降级 + 逐级 lastError + 20s 超时（授权 code 只在最后一步重试，不重复请求 authorize）
   - 酷狗补全的登录 cookie 已用于播放链接解析（`getPlayUrl` 携带 Cookie，仅发 kugou.com）
   - 失败提示：`MusicPlatformApi.lastError` 由接口层回报，设置页取码/轮询/登录成功降级都会展示
   - 接口清单与失效替换指引：`docs/接口清单.md`
4. 音乐库：收藏、播放历史（去重、200 条上限）、自建歌单、下载管理
5. 下载：播放页下载当前歌曲；音乐库「下载」页可播放/定位/删除
6. 桌面：全局快捷键、窗口置顶、系统托盘（关闭收进托盘）、迷你播放窗口
7. Android 发布：release 签名、INTERNET/媒体权限、明文流量放行
8. 歌单 / 榜单交互（0.9.9）：
   - 歌单详情（QQ/网易云/酷狗）按实际加载首数展示、错误/空态可重试；QQ 歌单详情需 `Referer: y.qq.com`（缺了会返回空 songlist，详见 `docs/接口清单.md`）
   - 歌单详情页、我的歌单页底部常驻迷你播放器（整页路由不再盖住 ShellPage 的 PlayerBar）

- **扫码登录已实扫验证（2026-11-09）**：QQ（p_skey→authorize code→QQLogin 业务 code=0）与网易云（eapi 803 + MUSIC_U）均在 MuMu 模拟器实扫登录成功、重启后仍已登录；证据见 `docs/projects/扫码登录修复/`。未覆盖：QQ VIP 点播、酷狗 token_get 成功路径、最终包网易云复扫
- **网易云 8821 风控**：旧「网页模拟」协议（`/api` + `type=1`）在手机确认后返回 8821；已迁移 eapi 解决。若后续再遇 8821，说明账号/网络触发风控或协议再变，按 `docs/接口清单.md` 排查
- **交付构建白屏坑（本次已踩过）**：干净 worktree / 新环境构建前若未生成 `GeneratedPluginRegistrant.java`，会打出缺插件注册类的 APK → 装包启动白屏 + `ClassNotFoundException: GeneratedPluginRegistrant`；构建后必须做 classes.dex 字符串检查 + 模拟器冒烟启动到首页（坏包 `445BE3A0` 已废弃留证）
- **未真机扫码（仅酷狗剩余）**：酷狗 `login_by_token_get` 的 status==1 / secu_params 解密未端到端执行；加密实现正确≠服务端密钥派生约定正确（酷狗三候选即兜底）。QQ/网易云已实扫通过。
- 酷狗三候选按序尝试存在"token 被首次请求消费但响应丢失"的幂等风险；失败会降级为 userid+token 会话，不阻断登录
- 平台接口会变动：QQ 带 u1 的请求在本机出口仍被 403；**QQ 歌单详情对 Referer 敏感**（缺 `Referer: y.qq.com` 会返回空 songlist，0.9.9 已修复并写入 `docs/接口清单.md`）；接口失效按 `docs/接口清单.md` 一处替换（公共参数/候选列表已集中）
- 网易云图片 CDN 对「组合 UA」返回 403 的坑已从根上规避（不要再把 UA 塞进 `Image.network(headers:)`）；改图片 UA 只改 `JXNetworkImage` 的 `HttpClient.userAgent`
- APK 体积约 102MB（libmpv + 托盘等原生依赖），如需缩小需裁剪 ABI 或按需打包
